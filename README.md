# Student Grade Calculator & Analyzer 

This is a Python project that calculates student grades and analyzes class performance.

## Features
- Grade calculation (A, B, C, D, F)
- Class average
- Highest & lowest scorer
- Pass/Fail percentage
- Grade distribution graph
- Individual student report

## How to Run
1. Install Python
2. Run:
   python student_grade_analyzer.py
